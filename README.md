=====Descrição====
* É um sistema simples de gerenciamento de biblioteca desenvolvido em TypeScript. Os dados dos livros são armazenados em arrays paralelos, onde cada posição representa um livro com suas informações como título, autor, ano, páginas, status de leitura e avaliação.
* O sistema permite adicionar, remover, buscar livros, além de gerar estatísticas e organizar os livros por década.

====Instruções de Execução====
* Instalar as dependências com o comando:
npm install

* Executar o projeto com o comando:
npm run dev
